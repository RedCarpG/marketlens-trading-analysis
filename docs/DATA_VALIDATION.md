# P0 免费数据核验计划

日期：2026-10-22；仅规格/核验计划，不是已完成的接口测试。

## 已查证与尚未查证

eToro官方FAQ表示符合资格用户无需单独API订阅费；Market Data提供报价和历史OHLC。入口要求验证账户。GOLD页面描述跟踪现货黄金的CFD并使用TradingView图表。这些事实不能证明用户账户已获权限，也不能证明能获取250根周线或完整1h历史。

来源：[FAQ](https://builders.etoro.com/faq)、[市场数据](https://builders.etoro.com/products/market-data-realtime)、[开发者入口](https://api-portal.etoro.com/)、[GOLD](https://www.etoro.com/markets/gold)。

## 顺序与完成条件

1. 图表使用方式已确认：主要独立TradingView，项目不绑定图表平台。先比较候选源的免费资格、历史长度、周期与许可，再选单一主源；不以取得TradingView代码或eToro权限作为规划前置条件。
2. 若选择账户型数据源，再核实只读行情权限。未开通时不默认要求开新账户或付费。凭据只在之后获准的接入步骤本地保存，不通过聊天传递。
3. 通过所选源的官方品种元数据核对黄金标识、计价货币、类型、交易时段与报价口径，不能猜ID。eToro普通GOLD与Gold 24/7等产品分别辨识；精确对照TradingView时再记录完整代码。
4. 只读获取周/日/4h/1h样本。记录支持的interval、最大条数、最早日期、分页方法、收盘语义、修订行为、调用额度。周线目标250根；缺少任一周期应报告不足。若需聚合，先确认会话边界和缺线规则。
5. 选取至少20个相同已收盘时间点，核对MarketLens数据与所选源参考图表的OHLC、时区及精度。对照其他平台时另记bid/ask/mid和会话差异，不要求不同来源数值相同，不把趋势相近认定为点位可直接互用。
6. 核实内部显示、自动计算、历史保存及手动外发摘要的许可。无法核实时停在离线研究，不通过抓取绕过限制。
7. 决策：全部满足则可进入本地实现；缺历史则先回放验证；账户无权限则评估合法历史文件或其他免费源。付费选项只提交对比，不自动订阅。

## 无API时的离线路线

导入用户有权使用的OHLC文件，必备字段timestamp、open、high、low、close，附provider、symbol、timeframe、timezone、price_type与数据截至时间；volume可空。原始文件只读保存，不入Git。界面显著显示“历史/离线”，停用当前行情触发提醒。

合成数据仅用于界面和边界测试，不用于声称预测能力或给真实入场点位。截图可辅助核对但不能替代长期OHLC。若缺乏可用免费数据，输出具体缺口而非悄悄换成黄金期货。

## 手动ChatGPT分析包契约

文件为UTF-8 Markdown或复制文本，含export_id、生成时间、行情截至时间、来源、报价类型、四周期完整性、指标定义/值、关键区域及证据、候选情景与失效条件、事件覆盖状态、已核实来源与未知项。模板要求ChatGPT按“事实→多周期解释→多空条件情景→观望条件→缺失信息”回答，不编造当前新闻或概率。

若分析包已经过时，先要求刷新；未接入事件时明确“本包未检查新闻/经济日历”。手动解读不是自动接入：程序不读ChatGPT回答，不把回答中的点位自动设为提醒条件。重要信号的即时说明由本地规则提供。
